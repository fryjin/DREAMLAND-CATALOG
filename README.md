## 验收

1. 进入提交确认页，检查“提交说明”。
2. 完成普通安全检查，提示应为“安全检查已完成，可提交。”
3. 触发并完成额外安全验证，提示应为“安全验证已完成，可提交。”
4. 确认详情轮播预加载优化仍然正常。

若仍显示旧文案，请关闭已有页面后重新打开；微信内置浏览器可能需要关闭全部相关页面后再进入。
