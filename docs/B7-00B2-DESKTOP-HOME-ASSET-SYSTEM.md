# B7-00B.2 — Desktop Home Asset System + Hover Refinement

## Purpose

Separate Desktop Home marketing/editorial imagery from canonical product media.

```text
Product data
→ name / price / MOQ / series / Product ID

Desktop Home Asset Contract
→ Hero / Collection / Featured / Craft / Custom / Wholesale imagery
```

Replacing a marketing image should not require a renderer change.

## Hover language

Removed:

```text
hover → angle image
```

Formal interaction:

```text
hover / keyboard focus
→ keep the same image
→ subtle 1.025 scale
→ warm dark gradient overlay
→ View details →
```

Collection cards use the same interaction language with `Explore →`.

Editorial imagery (Hero, Craft, Custom) remains visually static.

## Placeholder assets

The included files are deliberately replaceable placeholders designed around
the Warm Editorial direction. Replace them with final photography while keeping
the same filename and role.

See:

```text
images/desktop/home/README.md
```

for exact dimensions.
